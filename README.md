# FastDownloader Engine

FastDownloader Engine is the native binary component used by the FastDownloader application.

This repository contains the compiled engine required for the application to execute download tasks. The FastDownloader app uses this binary to perform media processing operations and receives updates through new engine releases published here.

FastDownloader Engine includes third-party open-source components required for its functionality:

- yt-dlp
- FFmpeg
- Deno
